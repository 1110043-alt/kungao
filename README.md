# 🚀 台灣股市預測器

一個強大的本地股市分析工具，實時顯示台灣熱門股票的技術指標、趨勢分析和上漲機率預測。

## 📋 功能特性

✨ **即時數據分析**
- 從 Yahoo Finance 實時獲取台灣股票數據
- 支援 8 支大眾熱門股票：台積電(2330)、聯發科(2454)、鴻海(2317)、玉山金(2884)、中華電(1313)、兆豐金(2886)、台泥(1101)、大立光(3008)

🤖 **AI 智能趨勢判斷** ⭐ 新功能
- 智能判斷股票是否有上升或下降的空間
- 計算上升空間百分比和下跌空間百分比
- 設定上升和下降目標價位
- 信心度評分（0-100%）
- 多指標綜合判斷（RSI、均線、MACD、支撐阻力）

📊 **技術指標**
- 移動平均線 (MA20/50/200)
- 相對強弱指數 (RSI)
- MACD 指標
- 布林帶 (Bollinger Bands)
- 波動率分析
- 支撐阻力位

🎯 **預測功能**
- 基於統計分析的上漲機率預測
- 趨勢判斷 (強勢上升/下降、中期上升/下降)
- 行情監控儀表板

📈 **可視化**
- 互動式股價走勢圖
- 精美的卡片式概覽
- 詳細的技術指標分析

## 📦 快速開始

### 方式一：直接點擊啟動 (最方便)

1. **點擊 `啟動.bat` 文件** 雙擊打開
   - 程序會自動配置環境和安裝依賴
   - 首次運行可能需要 1-2 分鐘

2. **瀏覽器會自動打開** (或手動打開 http://localhost:5000)

3. **按 Ctrl+C 停止應用**

### 方式二：使用命令行 (進階用戶)

```powershell
# 進入項目文件夾
cd C:\Users\USER\Desktop\taiwan-stock-predictor

# 建立虛擬環境
python -m venv venv

# 激活虛擬環境
venv\Scripts\activate

# 安裝依賴
pip install -r requirements.txt

# 啟動應用
python app.py
```

然後在瀏覽器中打開 `http://localhost:5000`

## 📊 技術指標說明

| 指標 | 說明 | 應用 |
|------|------|------|
| **MA (移動平均線)** | 平滑股價趨勢 | MA20 > MA50 > MA200 = 強勢上升 |
| **RSI (相對強弱)** | 0-100 的動量指標 | < 30 超賣，> 70 超買 |
| **MACD** | 動量震蕩指標 | MACD > Signal 線 = 買入信號 |
| **布林帶** | 價格波動區間 | 價格觸及上/下軌可能反彈 |
| **波動率** | 年化波動率 | 高波動率 = 風險大，低波動率 = 風險小 |
| **上漲機率** | AI 預測 | 綜合技術指標的預測概率 |

## ⚙️ 自定義設置

### 修改追蹤股票

編輯 `app.py`，找到以下位置：

```python
STOCK_CODES = {
    '3037': '奇鎰科技',
    '1785': '光磊',
    '6548': '長科',
    '2313': '華碩',
    '2376': '技嘉'
}
```

將股票代碼替換為你想追蹤的股票。

### 修改刷新頻率

編輯 `app.py`，找到：

```python
CACHE_DURATION = 300  # 5 分鐘快取
```

修改為其他值（單位：秒）

### 修改刷新間隔

編輯 `static/script.js`，找到：

```javascript
setInterval(loadStocks, 30000);  // 30 秒
```

## 🐛 常見問題

### Q: 程序無法啟動
**A:** 
1. 確保已安裝 Python 3.8+
2. 運行命令檢查：`python --version`
3. 如果未安裝，從 https://www.python.org/downloads/ 下載安裝

### Q: 無法獲取股票數據
**A:**
1. 檢查網路連接
2. Yahoo Finance 可能暫時無法訪問
3. 等待幾分鐘後重試

### Q: 應用啟動但網頁無法打開
**A:**
1. 檢查防火牆設置
2. 手動打開瀏覽器，訪問 http://localhost:5000
3. 檢查控制台是否有錯誤信息

### Q: 如何修改預測算法?
**A:** 編輯 `prediction_engine.py` 中的 `predict_upside_probability()` 方法
