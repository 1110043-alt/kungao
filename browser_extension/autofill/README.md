# 多帳號自動結帳填表助手 - 瀏覽器擴充包

## 📦 擴充包文件結構

```
browser_extension/autofill/
├── manifest.json              ← 擴充包配置
├── background.js              ← 背景腳本（Service Worker）
├── content-script.js          ← 內容腳本（在網頁中執行）
├── data-manager.js            ← 資料管理核心
├── popup.html                 ← 擴充包界面
├── popup.css                  ← 樣式
├── popup.js                   ← 界面邏輯
└── README.md                  ← 本文件
```

---

## 🚀 安裝方式

### Chrome 瀏覽器

1. **開啟擴充功能管理頁面**
   - 地址欄輸入: `chrome://extensions/`

2. **啟用開發者模式**
   - 右上角開啟「開發者模式」開關

3. **載入擴充包**
   - 點擊「載入未封裝項目」
   - 選擇 `browser_extension/autofill` 資料夾

4. **完成！** ✅
   - 擴充包圖標出現在工具欄

### Edge 瀏覽器

1. **開啟擴充功能管理頁面**
   - 地址欄輸入: `edge://extensions/`

2. **啟用開發者模式**
   - 左下角開啟「開發者模式」開關

3. **載入擴充包**
   - 點擊「載入未封裝項目」
   - 選擇 `browser_extension/autofill` 資料夾

4. **完成！** ✅

## 💡 使用方式

### 基本流程

1. **點擊擴充包圖標**
   - 打開擴充包界面（Popup）

2. **選擇資料和卡號**
   - 從下拉菜單選擇個人資訊
   - 從下拉菜單選擇信用卡
   - 或使用快速組合按鈕（如：A+B）

3. **點擊「自動填表」**
   - 擴充包自動掃描網頁表單
   - 自動填入所有對應欄位

4. **手動確認並送出**
   - 檢查所有欄位內容
   - 手動點擊「送出」或「確認付款」

### 快速組合

可使用預設的快速組合按鈕：
- **A+A**: 資料 A + 卡號 A
- **A+B**: 資料 A + 卡號 B
- **B+A**: 資料 B + 卡號 A
- **B+B**: 資料 B + 卡號 B
- **C+A**: 資料 C + 卡號 A
- **C+B**: 資料 C + 卡號 B

## 🔧 管理資料

### 新增個人資訊

1. 點擊「管理資料」標籤
2. 填入「新增個人資訊」欄位
3. 點擊「新增資料」

### 新增信用卡

1. 點擊「管理資料」標籤
2. 填入「新增信用卡」欄位
3. 點擊「新增卡號」

### 刪除資料

1. 點擊「管理資料」標籤
2. 從下拉菜單選擇要刪除的資料/卡號
3. 點擊「刪除資料」或「刪除卡號」

## 🐛 常見問題

### Q: 擴充包為什麼沒有反應？
**A:** 
1. 確認擴充包已啟用（應有彩色圖標）
2. 重新載入網頁
3. 檢查瀏覽器控制台是否有錯誤

### Q: 自動填表沒有填入某個欄位？
**A:** 
1. 該欄位名稱可能不在自動偵測清單中
2. 可以手動填入
3. 回報欄位名稱以便改進

### Q: 可以同時使用多個資料組嗎?
**A:** 
1. 可以，只需在每次使用前重新選擇
2. 支援無限擴充資料數量

### Q: 資料安全嗎？
**A:** 
1. 所有資料存儲在本地瀏覽器
2. 不會上傳到任何伺服器
3. 只要不清除瀏覽器數據就會保留

### Q: 如何重置所有資料？
**A:** 
1. 點擊「設定」標籤
2. 點擊「重置所有資料」
3. 確認操作
