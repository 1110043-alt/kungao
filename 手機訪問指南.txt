📱 手機和其他設備訪問指南
================================

【啟動方式】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💻 電腦上：雙擊 "後台啟動.vbs"
   - 應用會在後台執行，不顯示黑色窗口
   - 即使關閉提示框，應用也會繼續運行
   - 關閉電腦或登出帳戶應用會停止


【手機/平板訪問】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1️⃣ 先找到電腦的IP位址：
   
   Windows（快速方法）：
   - 開始功能表搜尋「cmd」
   - 輸入：ipconfig
   - 找到 "IPv4 位址" 例如：192.168.1.100

2️⃣ 在手機瀏覽器輸入：
   
   http://192.168.1.100:5000
   
   （將 192.168.1.100 改為您電腦的 IP）

3️⃣ 按 Enter 開啟網站


【常見問題】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❓ 手機無法連接
   ✓ 確認手機和電腦連接同一個 WiFi
   ✓ 防火牆可能阻止，允許 Python 通過防火牆
   ✓ 檢查 IP 位址是否正確
   ✓ 試試多等幾秒或重新整理頁面

❓ 要停止應用
   ✓ 電腦上雙擊 "停止應用.cmd"

❓ 應用重新啟動時會停止嗎
   ✓ 不會，除非您：
     • 關閉電腦
     • 登出 Windows 帳戶
     • 手動執行 "停止應用.cmd"


【進階：永久後台運行】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
若想設置開機自動啟動：

1. 按 Windows + R，輸入 shell:startup
2. 把 "後台啟動.vbs" 複製到該資料夾
3. 下次開機應用會自動啟動


【使用建議】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 最佳實踐
   • 電腦接電源長期運行
   • 不要關閉系統
   • 定期檢查應用是否運行

⚠️ 注意事項
   • 這是本地網路應用（只能在家用WiFi訪問）
   • 公網上無法訪問
   • Flask 是開發服務器，不適合生產使用
